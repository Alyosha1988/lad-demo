# my-project

## Лад — помощник гитариста

Интерактивный гармонический компас для тех, кто пишет песни на гитаре.

1. Выбираете **стартовый аккорд**
2. Отвечаете на вопросы (краска, направление, форма, гармонический язык)
3. Получаете **каталог последовательностей** по семействам: диатоника, каденции, блюз, джаз, модальность, соул/госпел, латина, рок/металл, хром/заимствования — плюс лады и мелодические подсказки

Тестовая ссылка: https://alyosha1988.github.io/lad-demo/

Под каждым ходом — **последовательность аппликатур** (с номерами шагов и стрелками):
на гитаре формы подобраны с малым сдвигом руки; на рояле — клавиатура, ноты и пальцы с голосоведением.
Переключение иконки инструмента сразу меняет тип схем.

### Как открыть

Самый простой способ — открыть файл `index.html` в браузере (двойной клик).

Или из папки проекта:

```bash
python3 -m http.server 8000
```

Затем открыть в браузере: http://localhost:8000
